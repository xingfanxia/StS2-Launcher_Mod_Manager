## Baseline causality rules

- Treat the earliest error that changes control flow or process state as the causal candidate; record the terminal exit separately.
- `QueuePresentKHR`, `queueBuffer`, or swapchain errors after `onPause`, surface destruction, or process teardown are consequences unless an earlier first-frame failure proves otherwise.
- Absence of a managed exception in self-captured logcat is not evidence of a clean exit. Use the following boot's `ApplicationExitInfo`, system tombstone/native symbols where authorized, and heartbeat/lifecycle boundaries.
- A third-party failure is not marked fixed merely because all mods were disabled. The no-mod run establishes the launcher boundary; the smallest failing mod set establishes attribution.
